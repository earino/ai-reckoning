# Corrections

We correct factual errors openly.

## How to report an error

Open an issue at <https://github.com/earino/ai-reckoning/issues> with:

1. The sentence, chart or data field that is wrong.
2. What you believe is correct.
3. A source.

## How corrections are handled

- A confirmed error is fixed in the data or text, the site is rebuilt, and an entry is added below with the date, what was wrong, and what changed.
- If a correction changes a finding, the change is also recorded in the [research log](#/research-log).
- The methodology version number changes when a method changes.
